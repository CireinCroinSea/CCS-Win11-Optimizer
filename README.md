# 🎮 Win11 Gaming Optimizer

### ⚡ Больше контроля. Меньше лишнего. Комфортнее игра.

**Win11 Gaming Optimizer** — утилита для Windows 11, объединяющая инструменты оптимизации, мониторинга системы и диагностики проблем в одном удобном интерфейсе.

<p align="center">
  <strong>🖥️ SYSTEM MONITORING · 🎯 GAMING · ⚡ OPTIMIZATION</strong>
</p>

---

## ✨ Возможности

| Функция | Описание |
|---|---|
| 🖥️ **Состояние ПК** | Информация о системе и её ресурсах |
| 🌡️ **Температуры** | Мониторинг доступных температурных датчиков CPU, GPU и других компонентов |
| 📊 **Мониторинг процессов** | Топ-15 процессов по загрузке процессора |
| 🌐 **Сеть** | Скорость получения и отправки данных |
| 🧹 **Очистка** | Инструменты очистки системы |
| 🚀 **Автозагрузка** | Управление программами, запускающимися вместе с Windows |
| 🎮 **Игры** | Инструменты для игровой системы |
| 🔧 **Диагностика** | Проверка драйверов и поиск возможных узких мест |

## 🛠️ Технологии

- C#
- Windows Forms
- .NET 8
- LibreHardwareMonitor

## 🚀 Сборка

1. Установи **.NET 8 SDK**.
2. Скачай или клонируй этот репозиторий.
3. Открой папку проекта.
4. Запусти `Собрать_EXE.bat` либо собери проект через Visual Studio.

> Некоторые датчики и функции мониторинга зависят от оборудования, драйверов и прав доступа Windows.
