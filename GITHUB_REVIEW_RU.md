# Обзор открытых Windows-оптимизаторов — 09.10.2026

Публичные проекты, которые посмотрели как источники идей, а не как код для копирования:

- Chris Titus Tech WinUtil: https://github.com/ChrisTitusTech/winutil — популярный проект с наборами пресетов и отдельными системными задачами; в поисковой выдаче GitHub отображается более 63 тыс. звёзд.
- Sophia Script for Windows: https://github.com/farag2/Sophia-Script-for-Windows — большой набор настраиваемых твиков, у которых предусмотрены соответствующие функции возврата.
- SophiApp: https://github.com/Sophia-Community/SophiApp — GUI-проект, полезный как пример структурирования большого числа настроек.
- GameOptimizerPro: https://github.com/FloDePin/GameOptimizerPro — проект с акцентом на Apply/Revert, проверку состояния и журналы действий.

## Что заимствовано на уровне идей в этом проекте

Код перечисленных проектов не копировался. Добавлены собственные реализации следующих практик:

1. **Журнал действий.** Вкладка «Журнал» показывает действия, изменения и ошибки, а файл `Отчёты/Журнал_действий.log` сохраняется рядом с EXE. Журнал можно экспортировать. Очистка окна не удаляет историю с диска.
2. **Явное применение и сброс.** Твики не применяются при запуске автоматически. Для известных настроек есть отдельное действие сброса; если исходное значение не сохранялось, интерфейс предупреждает, что удаление параметра возвращает управление Windows, но не восстанавливает пользовательское значение.
3. **Проверка результата.** Там, где доступно, журнал фиксирует результат команды и ошибку; статус Windows Update проверяется отдельным действием. Визуальное состояние переключателя не считается доказательством состояния ОС.
4. **Прозрачность рисков.** Диагностические сигналы названы предварительными; не обещается гарантированный прирост FPS.

## Что сознательно не добавлено

- Автоматические резервные копии и точки восстановления — пользователь ранее явно просил не создавать автоматические бэкапы.
- Массовое отключение служб, Defender, Firewall или механизмов безопасности.
- Необратимые «секретные FPS-твики» без документированного эффекта.
- Скачивание и выполнение удалённого PowerShell-кода из интерфейса.

## Ограничение проверки

В текущей среде отсутствует .NET SDK и Windows runtime, поэтому C# проект нельзя собрать и запустить здесь. Архив и исходники проверяются статически; финальную компиляцию нужно выполнить на Windows командой `Собрать_EXE.bat`.
