Дополнительные твики (октябрь 2026)

Добавлены в «Оптимизация»:
1. Отключить прозрачность Windows — низкий риск, эффект на FPS в играх обычно отсутствует или минимален; влияет на вид рабочего стола.
2. Убрать задержку автозапуска приложений — средний риск/изменение поведения: приложения могут запускаться плотнее сразу после входа в Windows. Это не FPS-твик.
3. Отключить советы и предложения Windows — низкий риск, настройка интерфейса/удобства, не FPS-твик.

У каждого параметра есть обратное действие. Сброс удаляет изменённое значение, возвращая управление Windows по умолчанию; это не восстанавливает вручную заданное пользователем значение, если оно существовало до применения.

Идеи по организации функций изучались по открытому проекту Chris Titus Tech WinUtil:
https://github.com/ChrisTitusTech/winutil
Использованы общие идеи категоризации твиков и обратимости настроек; чужой исходный код не копировался.

Рекомендации по производительности Windows от Microsoft:
https://support.microsoft.com/en-us/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows
Оптимизация оконных игр Windows 11:

Важно: новые пункты не обещают прирост FPS. Для игрового ПК лучше менять по одному параметру, проверять frametime в одинаковой сцене и откатывать настройку при ухудшении.
